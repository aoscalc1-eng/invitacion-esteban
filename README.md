# Invitación Baby Shower de Esteban

Proyecto Angular listo para abrir en Visual Studio Code.

## Cómo abrirlo

1. Descomprime la carpeta.
2. Abre `invitacion-esteban-angular` en Visual Studio Code.
3. Abre la terminal.
4. Ejecuta:

```bash
npm install
npm start
```

5. Abre en el navegador:

http://localhost:4200
